# Exercises - C Programming for MSc AE

This directory contains practice exercises to reinforce C programming concepts.

## Exercise Categories

### Basics
1. **Hello Name**: Modify hello_world.c to ask for user's name and greet them
2. **Unit Converter**: Write a program to convert between km/h and m/s
3. **Temperature Converter**: Convert between Celsius and Fahrenheit

### Control Structures
4. **Grade Calculator**: Calculate letter grade from numerical score
5. **Prime Numbers**: Find all prime numbers up to N
6. **Factorial Calculator**: Calculate factorial iteratively

### Functions
7. **Distance Calculator**: Calculate distance between two 3D points
8. **Reynolds Number**: Calculate Reynolds number for flow analysis
9. **Power Function**: Implement power function without using pow()

### Arrays
10. **Data Sorter**: Sort an array of sensor readings
11. **Matrix Operations**: Add and multiply 2D matrices
12. **Moving Average**: Calculate moving average of time-series data

### Pointers
13. **Array Reversal**: Reverse an array using pointers
14. **String Functions**: Implement strlen, strcpy using pointers
15. **Linked List**: Create a simple linked list implementation

### Advanced
16. **Flight Simulator**: Create a mini flight simulator with multiple aircraft
17. **CSV Parser**: Read and parse CSV files with flight data
18. **Numerical Integration**: Implement trapezoidal rule for integration

## How to Submit

Create your solutions in files named `exercise_XX.c` where XX is the exercise number.

Example: `exercise_01.c` for the first exercise.

## Tips

- Always compile with warnings enabled: `gcc -Wall -Wextra`
- Test your programs with various inputs
- Add comments to explain your logic
- Handle edge cases and errors

## Solutions

Solutions will be provided in the `solutions/` subdirectory after you attempt the exercises.
